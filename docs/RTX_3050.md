# RTX 3050 Local Generation Guide

LTX Video Director Studio now detects RTX 3050 laptop GPUs at launch and applies a conservative low-VRAM profile before any generation pipeline is imported.

## Supported studio modes

The hardware profile is applied below the UI layer, so the same runtime budget is used by:

- General text-to-video
- General image-to-video
- Comics Studio
- Real World Studio
- Action Studio
- Cartoon Story Studio
- Multi-scene continuation and MP4 delivery exports

## Recommended launch

```powershell
python -m venv venv
venv\Scripts\activate
python run.py --check
python run.py
```

Always launch with `python run.py` so the detected GPU profile is applied before the generator is loaded.

## RTX 3050 4 GB

Runtime defaults:

- GPU placement budget: `3GiB`
- CPU offload budget: RAM-aware, normally `9GiB` on a 16 GB laptop
- Safest first clip: `384x224`, `49` frames
- Native single-clip cap: `121` frames (about 4 seconds at 30 FPS)
- 8-bit text encoder and transformer loading
- VAE tiling/slicing remains enabled

For longer output, use Cartoon Story / multi-scene generation so each scene stays inside the low-memory native limit and the final clips are stitched together.

## RTX 3050 6 GB

Runtime defaults:

- GPU placement budget: `4GiB`
- Safest first clip: `384x224`, `49` frames
- Native single-clip cap: `193` frames

## RTX 4050 6 GB

The existing higher-capacity path is preserved:

- GPU placement budget: `5GiB`
- Native single-clip cap: `241` frames

## First generation

Start with:

```text
Resolution: 384x224
Frames:     49
Duration:   ~1.6 seconds
Steps:      12-20
```

After that succeeds, increase frames first. Increase resolution only after the chosen duration is stable.

## If CUDA runs out of memory

1. Close browsers, games, screen recorders, and other GPU-heavy apps.
2. Restart `python run.py` to clear the pipeline.
3. Return to `384x224 / 49 frames`.
4. Keep Windows virtual memory/page file enabled because CPU offload is part of the 3050 path.
5. Use multi-scene generation instead of one very long native clip.

The RTX 3050 profile is designed to make the existing studios usable on lower VRAM hardware; actual speed and maximum stable settings still vary by laptop power limit, available system RAM, driver, CUDA/PyTorch build, and other processes using VRAM.
