# RTX 4050 Demo Capture Guide

This folder is reserved for **real output generated by this repository on the stated local hardware**. Do not publish cloud-generated footage here and label it as RTX 4050 proof.

## 1. Verify the machine first

```powershell
python run.py --check
```

Save the console output with the demo notes. The report should show the detected GPU, CUDA status, FFmpeg availability and whether the model cache is ready.

## 2. Capture four short examples

Use conservative native settings first. The target reel should contain:

1. **Text → Video** — General or Real World Studio.
2. **Image → Video** — animate a supplied reference image.
3. **Action Studio** — one clearly readable action beat and one camera move.
4. **Cartoon Story** — at least two connected scenes using continuity/reference anchoring.

Recommended first settings:

```text
Resolution: 384×224
Frames:     49 or 121
FPS:        30
Seed:       record the exact value
Steps:      record the exact value
```

If a 720p/1080p export is shown, label it as a **delivery resize**, not native diffusion resolution.

## 3. Record reproducibility data

For every clip, record:

| Field | Value |
|---|---|
| GPU | NVIDIA GeForce RTX 4050 Laptop GPU (exact detected string) |
| System RAM | 16 GB or actual value |
| Studio | General / Real World / Action / Cartoon Story |
| Prompt | Exact prompt used |
| Reference image | File name / none |
| Resolution | e.g. 384×224 |
| Frames | e.g. 49 |
| Approx. duration | e.g. 1.6 s |
| Seed | Exact seed |
| Steps | Exact steps |
| Guidance | Exact value |
| Generation time | Wall-clock time |
| Output file | Relative path or hosted URL |

## 4. Suggested repository layout

```text
docs/demo/
├── README.md
├── rtx4050-demo.mp4          # keep only if repository size remains reasonable
├── preview.webp              # lightweight README preview if practical
└── demo-notes.md             # prompts, settings, timings and hardware proof
```

Large media can be hosted externally instead; keep `demo-notes.md` in the repository so the result remains reproducible.

## 5. README publication rule

Only replace the README's "Real RTX 4050 demo" placeholder after the footage has actually been generated on the target system. Include the exact hardware/settings beside the media and link back to the reproducibility notes.
