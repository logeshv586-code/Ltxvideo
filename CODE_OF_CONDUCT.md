# Community Code of Conduct

LTX Video Director Studio welcomes users and contributors of different experience levels. Keep collaboration technical, respectful, and useful.

## Expected behavior

- Be respectful when reviewing code, prompts, demos, hardware results, and ideas.
- Critique the work rather than the person.
- Give reproducible details when reporting bugs or performance results.
- Respect licenses, privacy, and ownership of uploaded images, videos, prompts, and third-party assets.
- Clearly label generated media and hardware claims so other users are not misled.
- Help newcomers by pointing them to documentation, Discussions, and `good first issue` tasks.

## Not acceptable

Harassment, threats, discriminatory attacks, spam, deliberate misinformation, publishing another person's private information, credential leakage, or repeatedly disrupting project discussions are not acceptable.

## Moderation

Maintainers may edit, hide, lock, or remove content that breaks these expectations and may restrict participation when necessary to protect the project community.

For ordinary questions and ideas, use GitHub Discussions. For reproducible defects, use Issues. For sensitive security concerns, follow `SECURITY.md`.
